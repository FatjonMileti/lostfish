# Lost Fish

### We have both frontend and backend in the same directory

`lostfish` is the directory of client which is called `Lost Fish Dashboard` here in `readme` file and inside it we have
a folder `server` that include api files that will serve as the backend for this application.

In this document you can find details about it in the section below called `Lost Fish API` and you can see instructions
how to run it independently.

In the end of this file you have also information about running both applications in development mode in the section
called `Development`.
